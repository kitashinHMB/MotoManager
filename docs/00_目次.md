# Spring Boot 開発ノート

## 学習目的

JavaとSpring Bootを使用したWebアプリケーション開発の基本を理解する。

実際にバイクメンテナンス管理システム「MotoManager」を開発しながら、REST API、データベース操作、バックエンドの設計方法を学習する。
